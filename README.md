# Science of Placebo

A research hub and living bibliography for the science of placebo and nocebo effects: https://torwager.github.io/scienceofplacebo/ (to be mirrored at scienceofplacebo.org).

- **Daily search** of PubMed, Europe PMC and OpenAlex for new placebo/nocebo studies (`pipeline/run_daily.py`, run by `.github/workflows/daily.yml`).
- **LLM screening and tagging** against explicit inclusion criteria with a 13-axis controlled vocabulary (`pipeline/taxonomy.json`, `pipeline/prompts/classify_v1.md`, `pipeline/llm_client.py`). Works with Anthropic (preferred when `ANTHROPIC_API_KEY` is set) or OpenAI.
- **Database** as JSON in `data/papers/papers-YYYY.json`; every screened candidate is remembered in `data/screened.json`.
- **Static site** in `site/` (no build step; data files are generated by `pipeline/build_site.py` into `site/data/`).
- Seeded with the monthly lists of the [JIPS placebo database](https://jips.online/) (2016–2025) and a PubMed backfill.

## Local use

```bash
pip install -r requirements.txt
export OPENAI_API_KEY=...            # or ANTHROPIC_API_KEY
python -m pipeline.run_daily --days 5 --dry-run
python -m pipeline.build_site && (cd site && python -m http.server 8765)
```

One-time backfill scripts live in `scripts/` (`backfill_fetch.py` → `backfill_classify.py` → `backfill_merge.py`).
